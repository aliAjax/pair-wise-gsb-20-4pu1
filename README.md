# hxwl-06 显微镜玻片观察

样本、多倍率视野与染色观察记录库

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5106

## 功能

- 同一玻片按倍率分次录入视野记录（放大倍数 / 染色方式 / 观察结构 / 视野描述）
- 工作流：草稿 → 提交复核 → 管理员批准定稿；定稿后结论锁定、不可修改
- 对描述或染色信息有异议时，管理员可退回并写明原因，教师修改后重新提交
- 已批准结论与历史记录永久保留，补充高倍视野只能新增待复核记录
- 每条记录附复核时间线（提交 / 批准 / 退回及原因）
- 教师 / 管理员双角色切换，管理员有独立的复核台（待复核 / 已定稿 / 已退回）
- 数据保存在浏览器 localStorage，关闭页面后未提交的草稿与复核原因不会丢失
