# hxwl-06 显微镜玻片观察

样本、多倍率视野与染色观察记录库

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5106

## 功能

- **分次录入**：同一玻片可按放大倍率（40x–1000x）分次录入多条视野记录，每条记录含染色方式、观察结构与视野描述
- **草稿先行**：新记录先存为草稿（只需倍率与染色方式），可反复编辑，提交前仅教师可见可改
- **复核流转**：草稿提交后进入待复核；管理员在复核队列中逐条处理
  - 批准 → 结论定稿锁定，内容不可再改、不可删除
  - 退回 → 必须写明复核原因，教师按原因修改后可重新提交
- **定稿保留**：玻片已有定稿结论后，补录高倍视野只会新增待复核记录，旧记录与已批准结论全部保留
- **流转记录**：每条记录带完整时间线（创建 / 修改 / 提交 / 批准 / 退回及原因）
- **本地持久化**：全部数据保存在浏览器 localStorage，未提交的草稿与复核原因关闭页面后不丢失
- **双角色**：页面右上角切换「实验课教师 / 实验管理员」视角

## 角色操作一览

| 记录状态 | 教师 | 管理员 |
| --- | --- | --- |
| 草稿 | 编辑 / 提交 / 删除 | 只读 |
| 待复核 | 只读（等待复核） | 批准定稿 / 退回（必填原因） |
| 已退回 | 查看原因、修改后重新提交 | 只读 |
| 已定稿 | 只读 | 只读 |
